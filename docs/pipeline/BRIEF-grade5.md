# Задание: тема предмета «5 класс» по учебнику + казахский перевод

Репозиторий: /home/user/bil-prep-app (Next.js + Prisma, контент в `prisma/seed/data`). **Не делайте git commit/push/checkout** — только создавайте свои файлы. Коммитит координатор.

## Зачем
Новый предмет «5 класс» (на уровне «Математика» и «Логика»). Источник — сканы учебника «Математика» (EduCon), PDF в корне репозитория. Копировать учебник нельзя (авторское право), поэтому по каждому параграфу книги (= одна тема) нужно создать **собственный материал, похожий на книжный**: та же структура, те же идеи и уровень сложности, но **свои тексты, свои числа, свои имена, свои рисунки**. Ни одно условие, пример и решение не должны совпадать с книгой дословно, и числа в них должны быть другими.

## Вход
Книга задаётся в самом задании (файлы `001-075.pdf`… — «Математика 2»; файлы с префиксом `1-` — «Математика 1»). Сканы без текстового слоя, по 75 страниц в файле; номер страницы книги = индекс в PDF + смещение файла (2-й файл +75, 3-й +150, 4-й +225). Ваши файлы и страницы указаны в задании — проверьте границы параграфа на сканах (±1–2 страницы), не заходите в соседние параграфы. Рендер: `pdftoppm -r 90 -png -f P -l P файл.pdf <ваша папка>/p`, затем читайте картинки инструментом Read (по 1–2 страницы за раз; для мелких формул — `-r 120` и обрезка через PIL). Временные файлы кладите ТОЛЬКО в свою папку в `/tmp/claude-0/-home-user-bil-prep-app/5aeec68b-005a-5f9d-8c30-e34902dbe930/scratchpad/<код темы>/`.

Структура параграфа в книге: блок «Запомните» (теория) → «Пример N» с «Решением» → «Теперь попробуйте сами» → «Закрепление знаний» (много задач для письменного решения) → «ТЕСТ» (вопросы с вариантами A–E).

Типы и помощники: `prisma/seed/types.ts` (`int, dec, frac, mixed, seq, set, text`, виды рисунков). Формат разметки: `docs/content-format.md` (`{a/b}` дробь, `{w a/b}` смешанное число, блоки `:::rule/tip/warn/remember/fun/steps/check/example`, `:::figure {json}` в explanation, `###` заголовок, `**жирный**`). **Прочитайте оба файла целиком и один готовый пример темы** `prisma/seed/data/math2/section-1/v2/topic-1-1.ts` (русский) и `prisma/seed/data/kk/math2-1/1.1.ts` (казахский) — ваш результат должен быть в том же формате и того же уровня оформления.

## Часть A — русский
Создайте `prisma/seed/data/grade5/<book>/chapter-<C>/v2/topic-<C>-<P>.ts` (пути заданы в задании), `export default topic: SeedTopic`. Импорт: `import { SeedTopic, int, dec, frac, mixed, seq, set, text } from "../../../../../types";` (пять уровней вверх от `grade5/book-N/chapter-C/v2/`).

1. `code` = `"<C>.<P>"` (например `"4.1"`), `title` — название параграфа (как в книге).
2. **explanation** — своими словами: правила и определения (смысл тот же, формулировка своя), 3–8 примеров с решением (`:::example`), другими числами и именами, чем в книге; врезки `rule/remember/tip/warn/steps` по месту; рисунки — параметрические `:::figure` (см. ниже). Уровень: ученики 5–6 классов, дружелюбный тон.
3. **practice** («Закрепить тему») — открытый ответ (`ans`). Количество и разнообразие — как в разделе «Закрепление знаний» + «Теперь попробуйте сами» книги (та же логика и сложность, но новые числа/сюжеты). Если задача в книге не имеет проверяемого ответа («нарисуйте», «объясните») — замените близкой проверяемой.
4. **test** — вопросы `choice` из 5 вариантов A–E (ровно один верный, остальные — правдоподобные ошибки; позиция = буква), по количеству как в «ТЕСТ» книги. Разные тесты книги (ТЕСТ №1, №2…) объедините в один список подряд.
5. Номера `n`: строки `"1"`, `"2"`, … подряд (отдельно для practice и test). `pending: []`.
6. У каждой задачи `solution` — короткое пошаговое решение (для открытых задач обязательно; для тестов — тоже).
7. **Числа и ответы** считайте в Python (`fractions.Fraction`, `decimal`), не в уме. Десятичные ответы — `dec(...)`, целые — `int(...)`, дробь `frac`/`mixed` (неправильная дробь → `mixed`). Типы ответа: см. `docs/content-format.md`. Выражение — `text(...)` только если иначе нельзя. Всё, что ученик вводит, должно однозначно записываться (одно число/дробь).
8. **Имена**: казахские (Айдос, Бекзат, Данияр, Ернар, Жандос, Азамат, Нурлан, Тимур, Рустем, Мади, Алихан, Санжар, Арман, Диас, Мирас, Темирлан, Ильяс, Расул, Амир, Айгерим, Томирис, Мерей, Дана, Аружан, Амина, Дильназ, Жансая, Сабина, Меруерт, Назерке, Айжан, Салтанат, Гулнар, Балжан, Мөлдір, Аяулым, Сезім и т.п.), разнообразно, не повторяйте имена из книги. Деньги — тенге.
9. **Рисунки** рисуйте сами параметрическими видами из `types.ts` (`table`, `number_line`, `grid`, `fraction_bar`, `bar_chart`, `pie_chart`, `rectangle`, `scene` для прочего: примитивы в клетках). Не вставляйте `kind:"image"` с кусками книги — это копия. Если рисунок невозможно построить честно — перепридумайте задачу без рисунка. Рисунок обязан соответствовать условию (проверьте ещё раз, что числа в рисунке и в тексте совпадают с ответом).
10. Проверка: `npx tsx prisma/seed/validate.ts <ваш файл>` — без ошибок (если `node_modules` ещё нет — подождите и повторите; `npm install` запущен координатором).

## Часть B — казахский перевод
Создайте `prisma/seed/data/kk/<kkdir>/<код темы>.ts` (путь задан в задании; код темы с точкой, например `4.1.ts`):
```ts
import type { KkTopic } from "../index";
const kk: KkTopic = {
  title: "…",          // название БЕЗ кода темы
  explanation: `…`,    // полный перевод explanation, включая :::figure (caption и текст в таблицах)
  tasks: { "p:1": { question: "…", solution: "…" }, "t:1": { question: "…", options: ["…"], solution: "…" } },
};
export default kk;
```
Переведите ВСЕ задачи (`p:<n>`, `t:<n>`): `question`, `solution`, у тестов `options` (тот же порядок и количество; числа не трогайте). Если в рисунке есть русский текст — добавьте в задачу `figure:` с казахскими подписями. Числа, `{a/b}`, имена (казахское написание), порядок вариантов — те же, что в русском. Единицы: теңге, см, м, км, кг, г, л, мин, сағ, сек. Термины — нормативные казахские школьные (ондық бөлшек, бүтін бөлік, бөлшек бөлік, разряд — разряд/орын, жуықтау/дөңгелектеу, пайыз, жиын, бірігу, қиылысу, тізбек, және т.б.), стиль — грамотный нейтральный учебный казахский для 5–6 классов.
