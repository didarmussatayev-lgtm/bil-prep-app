## Что сделать (Часть A — русский)
Создайте **`prisma/seed/data/math3/section-<N>/v2/topic-<код с дефисом>.ts`**, `export default topic: SeedTopic` — полный самостоятельный файл (без overlay). Импорт типов: `import { SeedTopic, int, dec, frac, mixed, seq, set, text } from "../../../../types";` и `import { F } from "../figs/<код>";` (если файл figs есть).

1. **Имена.** Замените все имена персонажей на *другие* казахские (не оставляйте имена из исходника). Подбирайте из пула, разнообразно, мужские и женские: Айдос, Бекзат, Данияр, Ернар, Жандос, Азамат, Нурлан, Тимур, Рустем, Мади, Алихан, Санжар, Арман, Диас, Мирас, Темирлан, Ильяс, Расул, Амир, Бахтияр, Айгерим, Томирис, Мерей, Дана, Аружан, Амина, Дильназ, Жансая, Сабина, Меруерт, Назерке, Томирис, Айжан, Томирис, Салтанат, Гулнар, Балжан, Мөлдір, Аяулым, Сезім. Географию/предметы тоже можно менять (город, товар, животные), если это не ломает задачу.
2. **Числа.** В каждой задаче поменяйте числа, чтобы условие не совпадало с книгой, сохранив сложность (сопоставимый размер чисел, та же идея решения, «красивые» ответы там, где они были красивыми). Пересчитайте **ответ, решение, варианты A–E и букву правильного ответа**. Для варианта-теста должен быть ровно один верный вариант, остальные — правдоподобные ошибки. Всё считайте в Python (`python3 -c ...`/`fractions.Fraction`), не в уме; дробные ответы приводите к несократимому виду, если задача не про «не сокращая».
3. **Теория (`explanation`).** Правила и определения оставьте по смыслу (можно перефразировать), а все примеры перепишите с новыми именами и числами; рисунки в explanation (`:::figure`) приведите в соответствие с новыми числами.
4. **Рисунки.** Параметрические (`fraction_bar, circle, grid, number_line, table, cubes, rectangle, square, triangle, circle_measure, path_shape, box3d, cross, chain, circle_numbers`) — меняйте под новые числа. Рисунки `scene`/`image` (из `F`) **не меняйте**: если условие ссылается на числа/метки, изображённые на таком рисунке, оставьте эти числа и ответ прежними, меняйте только имена и числа, которых на рисунке нет. Если ответ зависит от рисунка и числа менять нельзя — меняйте только контекст/имена/формулировку. Но и такие задачи не должны совпадать с книгой дословно.
5. **pending → собственные задачи.** Каждый пункт `pending` (задания, которые раньше не загрузили: интерактивные, «нарисуйте», неоднозначные) замените своей задачей **той же логики**, пригодной для проверки: открытый ответ (`ans`) в закреплении или выбор в тесте. Рисунки к ним рисуйте сами параметрическими видами (или `scene`, если иначе нельзя; аккуратно, координаты в клетках). Номера для новых задач: `"s1"`, `"s2"`, … (для тестов тоже `s…`). В итоге `pending: []`. Если задачу невозможно сделать честно — придумайте близкую по теме, но не оставляйте пустой.
6. **Номера `n`** существующих задач **не меняйте** и не удаляйте задачи; порядок сохраните. Задачи из закрепления: открытые ответы (`ans`); тест: `choice` с 5 вариантами A–E (как в исходнике). Если в исходнике у задачи было поле `review`, проверьте и решите вопрос сами (пересчитайте), поле `review` в итоге не оставляйте.
7. Проверьте: `npx tsx prisma/seed/validate.ts <ваш файл>` — без ошибок.

## Часть B — казахский перевод
Создайте **`prisma/seed/data/kk/math3-<N>/<код темы>.ts`** (код с точкой, например `1.2.ts`):
```ts
import type { KkTopic } from "../index";
import { F } from "../../math3/section-<N>/figs/<код>"; // только если нужны подписи рисунков
const kk: KkTopic = {
  title: "…",                // название БЕЗ кода темы (код добавляет seed)
  explanation: `…`,          // полный перевод explanation, включая строки :::figure (подписи/caption переведите)
  tasks: { "p:1a": { question: "…", solution: "…" }, "t:1": { question: "…", options: ["…"], solution: "…" } },
};
export default kk;
```
Требования: переведите **все** задачи (`p:<n>` и `t:<n>`, включая новые `s…`): `question`, `solution` (если оно есть в русском), для тестов `options` (тот же порядок и количество; цифры/дроби оставьте как есть, переводите только слова). Числа, дроби `{a/b}`, формулы, имена и порядок вариантов — те же, что в вашей русской версии. Имена: кириллица, казахское написание, при склонении — с казахскими окончаниями. Единицы: теңге, см, м, км, кг, г, л, мин, сағ (час), сек. Термины возьмите из казахской книги (дробь — бөлшек, алымы/бөлімі, жай бөлшек, аралас сан, ортақ бөлім, қысқарту, салыстыру, пайыз, қатынас, пропорция — пропорция, және т.б.) — сверяйтесь со страницами книги, не выдумывайте. Если в рисунке есть русский текст (подписи таблицы, caption), добавьте в перевод задачи `figure:` с казахскими подписями (для рисунков из `F` берите `F["p:…"]` и подменяйте только текстовые поля, если они есть). Стиль: грамотный, нейтральный учебный казахский язык для 5-классников.
