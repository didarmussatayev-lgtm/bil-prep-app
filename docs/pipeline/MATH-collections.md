# Математика: варианты из сборников A и B (картинки как есть)

По решению заказчика задачи **не переписывались**: каждый вопрос вырезан из PDF картинкой (webp) вместе с вариантами ответов — как у 20 тренировочных тестов.

- Сборник A: `матем рус .pdf` (6math2021-int-NIS, Abay Academy) — математика 7 вариантов (вариант 7 — только 37 задач в книге) + количественные характеристики 3 варианта по 60. Картинки `public/exams/math/ca/`, варианты `math-collection-a-01…07`, `math-quant-a-01…03`.
- Сборник B: `матем + кол хар рус.pdf` — математика 10 вариантов по 40 + количественные характеристики 5 вариантов по 60. Картинки `public/exams/math/cb/`, варианты `math-collection-b-01…10`, `math-quant-b-01…05`.
- Всего 1157 вопросов, группа «past» («Реальные варианты»), `data/exams/math/manifest.json`. Ключи взяты из таблиц ответов в конце PDF (в А — столбцы 1в…7в и 1-вар…3-вар; в B — отдельные таблицы).
- К картинкам количественных характеристик сверху добавлена шапка с условием (A/B/C/D — что означает ответ), потому что в PDF оно дано один раз в начале варианта.
- Первый вопрос варианта 2 сборника B — картинка с номером, вырезан по расстоянию от заголовка.
- Не проверялось вручную: соответствие каждого из 1157 ответов ключу после нарезки (проверены выборочно: A в1 №1 = A, A quant1 №1 = B, B в1 №1 = D).
- Казахской версии картинок нет (в отличие от 20 тестов).
- Загрузка: `POST`/seed автозагрузки `importPapers()` берёт manifest сам (см. `src/lib/exam-import.ts`).
