## Часть A — русский (`v2`)
Создайте `prisma/seed/data/logic/<раздел>/v2/topic-<код>.ts`, `export default topic: SeedTopic` — полный самостоятельный файл. Импорт: `import { SeedTopic, int, dec, frac, mixed, seq, set, text } from "../../../../types";` (и `import { F } from "../figs/<код>";`, если оставляете оригиналы рисунков).

2. **Числа/буквы/фигуры.** В каждой задаче условие должно отличаться от книги: другие числа, другие буквы, другие закономерности той же сложности. Пересчитайте **ответ, решение, варианты A–E, букву правильного**. Для теста — ровно один верный вариант, остальные правдоподобные. Всё проверяйте кодом (Python): для задач на закономерность сначала задайте правило в коде, сгенерируйте ряд/рисунок/ответ из правила и сделайте `assert`, что правило однозначно (другого простого правила, дающего иной ответ, быть не должно).
3. **Рисунки — перерисовать, где можно.** Для каждой задачи с рисунком посмотрите оригинал и решите:
   - **Можно перерисовать** (числовые круги/треугольники/квадраты, таблицы и сетки с числами и буквами, ряды простых фигур, коды и шифры, спички, кубики/плоские развёртки, весы, фигуры на клетках, секторные диаграммы, часы и т. п.) → нарисуйте новый рисунок `scene` (или параметрический вид: `table`, `cubes`, `number_line`, `rectangle`…) с **новыми** числами/буквами/свойствами фигур, пересчитав ответ. Рисунок не должен быть копией оригинала; он должен быть читаемым, с подписями вариантов A–E, если варианты изображены. Разумно упрощать детали (оформление, фон), главное — та же логика и честная однозначность ответа.
   - **Нельзя перерисовать честно** (сложные иллюстрации, кривые и узоры, фото, объёмные композиции, мелкие детали) → оставьте оригинал: `figure: F["p:…"]`; тогда **числа/метки на картинке и ответ не меняйте**, меняйте только имена и формулировку (не дословно как в книге). Если на оставленной картинке русский текст — отметьте номер в отчёте.
   - Старайтесь, чтобы доля перерисованных рисунков была как можно выше; оставляйте оригинал только по необходимости.
4. **Просмотр результата.** `npx tsx prisma/seed/tools-render.ts <ваш v2-файл> <папка в scratchpad>` рисует ваши `scene`-рисунки в PNG-листы (`sheet-N.png`, 8 штук на лист, подпись `p:<n>`/`t:<n>`); откройте листы через Read и исправьте налезающие подписи, неверные пропорции, нечитаемые фигуры. Делайте это **в процессе** (по мере написания частей), а не только в конце.
5. **pending → собственные задачи.** Пункты `pending` — задания, которые раньше не загружали (ответ — рисунок, путь, раскраска, нечёткая закономерность). Замените их **своими задачами той же логики**, проверяемыми автоматически: открытый ответ (`ans`: число, буквы, `seq`, `set`) в закреплении или выбор A–E в тесте. Рисунки — свои `scene`. Номера новых задач `"s1"`, `"s2"`, … (в тесте тоже `s…`). Если пунктов `pending` больше 15, сделайте не меньше 12 новых задач, покрывающих все **разные виды** pending. В итоге `pending: []`.
6. **Номера `n`** существующих задач **не меняйте** (на них держится прогресс учеников), порядок сохраните, задачи не удаляйте. Закрепление — открытые ответы (`ans`), тест — `choice` с вариантами A–E, как в исходнике (если вариантов в исходнике было иное число — оставьте). Поле `review` в итоге не оставляйте (проверьте и решите вопрос сами).
7. **Ответы-слова.** Избегайте ответов, зависящих от языка (русское слово). Если в исходном ответе слово — переформулируйте так, чтобы ответ был числом, буквой (латиница) или номером варианта.
8. **Теория (`explanation`)**: правила сохраните (можно перефразировать), примеры перепишите с новыми числами/фигурами; рисунки в `:::figure` приведите в соответствие.

## Часть B — казахский перевод
Создайте `prisma/seed/data/kk/logic-<S>/<код>.ts` (S = 1, 2 или 3 по разделу; код — как у темы, например `20.ts`, `7.ts`):
```ts
import type { KkTopic } from "../index";
const kk: KkTopic = {
  title: "…",           // название БЕЗ кода темы
  explanation: `…`,     // полный перевод, включая строки :::figure (подписи)
  tasks: { "p:<n>": { question: "…", solution: "…", figure?: … }, "t:<n>": { question: "…", options: ["…"], solution: "…" } },
};
export default kk;
```
Переведите **все** задачи (`p:<n>` и `t:<n>`, включая новые `s…`): `question`, `solution`, `options` (тот же порядок/количество; цифры, буквы, формулы — как в русской версии). Рисунки `scene` с текстом на русском (слова в подписях): дайте в kk-задаче `figure:` с казахскими подписями (пересоберите рисунок с теми же координатами). Рисунки без слов (только числа/буквы/фигуры) переводить не нужно. Имена — те же, что в вашей русской версии (казахское написание). Единицы: теңге, см, м, км, кг, г, л, мин, сағ, сек. Термины берите из казахской книги по логике (сверяйтесь со страницами, не выдумывайте); стиль — грамотный нейтральный учебный казахский для школьников.
