# Слепая проверка ответов к задачам по математике

Вам даны файлы `*.json` со списками задач (id, q — условие, options — варианты A–E для тестов или answerType для открытых, figure — рисунок, если есть). Ответов нет — их нужно получить **самостоятельно**.

Правила:
- **Не открывайте** никакие файлы в `prisma/seed/` и вообще в репозитории (там лежат ответы — это испортит проверку). Работайте только с переданными json.
- Решайте каждую задачу сами; арифметику, дроби, проценты, перебор делайте в Python (`fractions.Fraction`, `decimal`), не в уме.
- Разметка: `{a/b}` — дробь a/b, `{w a/b}` — смешанное число, `Δ`, `▲` — неизвестные. Рисунки: `fraction_bar/circle/grid/number_line/table/rectangle...` — параметрические (читайте поля), `scene` — набор примитивов на сетке (rect/line/text/poly…): если вы не можете уверенно прочитать рисунок — ответьте "skip".
- Ответ для теста — буква `A`…`E` (какой вариант верный). Если ни один вариант не подходит, пишите `NONE`; если подходят два — `MULTI`.
- Ответ для открытой задачи по answerType: `int`/`dec` — число (десятичный разделитель точка или запятая); `frac` — `a/b`; `mixed` — `w a/b`; `seq` — элементы через пробел в нужном порядке; `set` — элементы через пробел; `text` — выражение.
- Выход: json-объект `{ "<id>": "<ответ>", ... }` в файл, который назвал координатор. В конце кратко перечислите задачи, где условие показалось некорректным/неоднозначным/без решения (id и почему).

**Обязательно:** каждую вычислимую задачу (арифметика, дроби, НОД/НОК, делимость, степени, перебор цифр, проценты, периметр/площадь) решайте кодом в Python и сверяйте результат с вашим рассуждением; в уме допустимо только то, что нельзя запрограммировать. Для задач вида «Верно/Неверно», «Да/Нет» и т.п. с вариантами A/B — ответ это буква варианта.
